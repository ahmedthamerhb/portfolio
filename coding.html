تطبيق المنيو الإلكتروني التفاعلي

Restaurant Menu App

منيو مطعم إلكتروني متكامل ومتجاوب مع جميع الشاشات، يتناول الفلترة الذكية وإرسال الطلبات مباشرة عبر الواتساب مع لوحة تحكم لإدارة الوجبات.

HTML5 CSS3 JavaScript (ES6+) WhatsApp API Integration
فلترة قائمة الأطعمة:

تنقل سريع بين الوجبات الرئيسية، المشروبات، والمقبلات دون الحاجة لإعادة تحميل الصفحة.

سلة طلبات تفاعلية:

إضافة الوجبات للسلة وحساب المجموع الكلي تلقائياً مع خيار كتابة ملاحظات الطلب.

إرسال مباشر للواتساب:

تحويل تفاصيل الطلب ومعلومات الزبون فوراً إلى رسالة منسقة عبر WhatsApp.

لوحة تحكم (Control Panel):

خاصية تمكّن صاحب المطعم من إضافة، تعديل، أو حذف الوجبات بسهولة.
